🥤 Refri do Dev

Projeto simples desenvolvido para praticar HTML, CSS e JavaScript.

A ideia do projeto é apresentar diferentes sabores de refrigerante em uma interface simples, utilizando JavaScript para controlar a navegação entre os itens.

🚀 Tecnologias
HTML5
CSS3
JavaScript
📌 Sobre o projeto

O projeto possui uma interface com diferentes opções de sabores, como:

🍓 Morango
🥑 Abacate
🍊 Laranja

Também conta com botões de navegação para alternar entre os sabores.

Foi desenvolvido principalmente como um projeto de prática e aprendizado, colocando em uso conceitos básicos de estrutura HTML, estilização com CSS e interação com JavaScript.
